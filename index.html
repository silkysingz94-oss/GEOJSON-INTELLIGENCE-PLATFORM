Gambia GeoJSON Intelligence — User guide

1. Data ingestion

Import GeoJSON or JSON files, or load a public GeoJSON URL. The application supports FeatureCollection, Feature and individual geometry objects.

2. Administrative geography

Load country, first-level or second-level administrative reference boundaries from geoBoundaries. These are not a substitute for authoritative GBoS boundaries.

3. Spatial operations

Buffer creates a new polygon around input features. Point-in-polygon selects points contained by polygons. Nearest finds the closest target feature to each source feature. Intersection identifies features that spatially intersect.

4. Measurements

Polygon area is measured in square kilometres and line length in kilometres using Turf.js. Results are geodesic approximations and may not replace projected, survey-grade measurements.

5. Data handling

Processing occurs in the browser. Uploaded data is not sent to a central server by this application. Public basemaps and boundary services are external dependencies.

6. Limitations

Large datasets may exceed browser memory or processing capacity. Geometry validation is a practical screening check, not a complete OGC topology certification. GeoJSON should use WGS 84 coordinates in longitude, latitude order.
